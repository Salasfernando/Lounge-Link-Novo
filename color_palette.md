# Paleta de Cores - Lounge Odontologia

## Cores Extraídas da Logo

A logo da Lounge Odontologia utiliza uma paleta sofisticada com tons naturais e profissionais:

1. **Azul Escuro (Teal/Petróleo)**: #1F4F4F ou similar
   - Cor principal, representa profissionalismo e confiança
   - Usado na maior parte da logo

2. **Bege/Caramelo (Tan/Beige)**: #C4A574 ou similar
   - Cor secundária, representa calidez e acessibilidade
   - Usado nos triângulos laterais

3. **Verde-Azulado (Teal médio)**: #4A7C7E ou similar
   - Cor de transição, representa equilíbrio
   - Usado nas áreas intermediárias

4. **Branco**: #FFFFFF
   - Fundo e espaço negativo

## Paleta Implementada no Projeto

```
--primary: #1F4F4F (Azul escuro/Teal)
--secondary: #C4A574 (Bege/Caramelo)
--accent: #4A7C7E (Verde-azulado)
--background: #FFFFFF (Branco)
--foreground: #1F4F4F (Azul escuro para texto)
```

Esta paleta transmite:
- **Profissionalismo**: Azul escuro é confiável
- **Acessibilidade**: Bege é acolhedor
- **Natureza**: Verde-azulado evoca bem-estar
- **Limpeza**: Branco representa higiene (importante para odontologia)
